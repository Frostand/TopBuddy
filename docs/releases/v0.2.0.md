# TopBuddy v0.2.0 — Lock In focus kits

This prerelease adds an opt-in, schedule-aware Lock In workspace while keeping TopBuddy local-first and empty by default.

## Included

- Per-block allowlists for exact HTTPS sites and installed macOS apps.
- A constrained WebKit browser that stops top-level navigation to unlisted domains.
- `openAtStart` rules so a resource can be allowed without opening automatically.
- Book, file, note, and physical-material instructions in the daily handoff.
- Immediate app hiding when an unlisted regular app comes to the front.
- Reason-gated 5, 10, 15, or 30 minute exceptions that exist only in memory.
- Lock In controls in setup, Settings, the dashboard, menu bar, and notch panel.
- Daily handoff schema v2, while retaining schema v1 decoding compatibility.

## Boundary

Lock In is a focus aid, not parental-control or tamper-resistant security software. It never force-quits apps, installs a network filter, uses Accessibility hooks, or removes the immediate **End Lock In** control.

## Privacy

The release contains no personal schedule, private link, account, credential, website history, pet, or exception reason. Schedules and settings remain local. Exception reasons and grants are cleared when Lock In ends or the active block changes.

## macOS release status

The attached universal build contains both Apple Silicon and Intel architectures. This prerelease is ad-hoc signed and is **not notarized**, because the project does not yet have a Developer ID signing identity. macOS may require a first-open confirmation.
