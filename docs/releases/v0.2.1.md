# TopBuddy v0.2.1 — Notch surface and control targets

This patch makes the expanded interface feel continuous with the physical MacBook notch and makes its controls substantially easier to hit.

## Included

- One calibrated near-black surface across compact and expanded notch states.
- Removal of the bright outer stroke and colored perimeter glow that exposed the software/hardware seam.
- 44-point header controls and page tabs.
- 50-point previous/next and 56-point play/pause controls in the Apple Music page.
- A larger capsule target for **Open Music** and larger utility controls throughout the notch.
- A wider hover activation area and a more forgiving pointer-exit margin.
- Explicit accessibility labels for icon-only controls.

## Privacy

The release contains no personal schedule, private link, account, credential, website history, pet, or other owner data. Existing schedules, completion state, pets, and settings remain local in Application Support during an update.

## macOS release status

The attached universal build contains both Apple Silicon and Intel architectures. This prerelease is ad-hoc signed and is **not notarized**, because the project does not yet have a Developer ID signing identity. macOS may require a first-open confirmation.
