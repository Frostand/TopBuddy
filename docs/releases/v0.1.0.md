# TopBuddy v0.1.0 MVP

TopBuddy's first public MVP is an empty-by-default, local-first macOS schedule companion for the MacBook notch.

## Included

- Permission-based first-run setup with Observe, Assist, and Focus presets.
- Per-capability choices for automatic resource opening, app hiding, manual quit review, Notion, Codex, Apple Music, and Apple Calendar.
- Markdown, TSV, and private JSON schedule import with overlap and resource-safety validation.
- Local completion tracking and explicit schedule rollover proposals.
- Community pet gallery plus local image and compatible sprite-sheet import.
- Compact and expanded notch states, current-block countdown, file shelf, focus utilities, and optional Music controls.
- No bundled schedule, account, private URL, pet asset, telemetry, or developer data.

## macOS release status

The attached universal build contains both Apple Silicon and Intel architectures. This prerelease is ad-hoc signed and is **not notarized**, because the project does not yet have a Developer ID signing identity. macOS may require a first-open confirmation. The source and reproducible packaging script are included for review.
